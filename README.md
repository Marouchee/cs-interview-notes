# CS Interview Notes

백엔드 기술 면접과 정보처리기사 준비를 위해 정리한 CS 개념 노트입니다.
매일 질문에 답하고 채점받으며 공부한 주제를 개념 위주로 정리합니다. 예시는 Python·MySQL 기준입니다.

## 구성

각 주제는 같은 순서로 정리합니다.

1. **한 줄 요약**: 면접에서 첫 문장으로 꺼낼 말
2. **정의**: 30초 안에 말할 핵심
3. **비교표·예시**: 왜 그런지, 무엇과 다른지
4. **꼬리 질문**: 면접에서 이어서 나오는 질문과 답
